# Architecture Decision Records

One file per important decision, numbered in order: `NNN-short-title.md`.
Each ADR has four sections: **Context**, **Options**, **Decision**, **Consequences**.
An accepted ADR is never edited to change its decision; write a new ADR that supersedes it.
